BULLDOGS TRACK & FIELD — STANDALONE WEBSITE + ADMIN DEMO

HOW TO OPEN
1. Extract the ZIP (keep the assets folder next to index.html).
2. Double-click index.html to open it in Chrome, Edge, or Firefox.
3. Scroll to the footer and select ADMIN STUDIO, or add #admin to the file URL.
4. Edit text, photos, programs, gallery images, and brand settings. Use VIEW WEBSITE to check changes.
5. Test the contact form; its submissions appear under Inquiries in this browser.
6. Use Settings & backup > DOWNLOAD BACKUP JSON before moving to another browser or clearing browser storage.

FEATURES
- Responsive public website, mobile menu, photo lightbox, editable content, program and gallery management.
- Upload/replace images, change logo, local inquiries list, export CSV, export/import content JSON, reset.
- No installation, hosting, backend, or network needed for core use. Google fonts may require internet; fallback fonts work offline.

IMPORTANT LIMITATIONS
- This is an OFFLINE BROWSER DEMO. Content is stored in browser localStorage for this one page/browser profile.
- Admin mode has NO AUTHENTICATION and is NOT SECURE. Do not upload/publish the demo as a real admin website.
- Inquiry submissions are local only and do NOT send email, reach Sean, or sync across visitors/devices.
- Uploaded photos are resized/encoded to reduce storage size. Browser localStorage can fill up. Export backups regularly.
- Some browsers limit file:// persistence; use the same file path and browser each time, or serve locally for more reliable persistence.
- A production launch requires a backend, secure authentication, database/media storage, and email delivery.
- The team photos are AI-edited branding concept images and may alter facial details; confirm photo rights/approval before publication.
